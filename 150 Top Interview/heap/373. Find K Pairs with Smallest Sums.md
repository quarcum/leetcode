# [373. Find K Pairs with Smallest Sums](https://leetcode.com/problems/find-k-pairs-with-smallest-sums/)  

### Medium level  

You are given two integer arrays <code>nums1</code> and <code>nums2</code> sorted in **non-decreasing order** and an integer <code>k</code>.

Define a pair <code>(u, v)</code> which consists of one element from the first array and one element from the second array.

Return *the* <code>k</code> *pairs* <code>(u1, v1), (u2, v2), ..., (uk, vk)</code> *with the smallest sums*.

<br />

**Example 1:**
<pre>
<strong>Input:</strong> nums1 = [1,7,11], nums2 = [2,4,6], k = 3
<strong>Output:</strong> [[1,2],[1,4],[1,6]]
<strong>Explanation:</strong> The first 3 pairs are returned from the sequence: [1,2],[1,4],[1,6],[7,2],[7,4],[11,2],[7,6],[11,4],[11,6]
</pre>

**Example 2:**
<pre>
<strong>Input:</strong> nums1 = [1,1,2], nums2 = [1,2,3], k = 2
<strong>Output:</strong> [[1,1],[1,1]]
<strong>Explanation:</strong> The first 2 pairs are returned from the sequence: [1,1],[1,1],[1,2],[2,1],[1,2],[2,2],[1,3],[1,3],[2,3]
</pre>

<br />

**Constraints:**

* <code>1 <= nums1.length, nums2.length <= 10<sup>5</sup></code>
* <code>-10<sup>9</sup> <= nums1[i], nums2[i] <= 10<sup>9</sup></code>
* <code>nums1</code> and <code>nums2</code> both are sorted in **non-decreasing order**.
* <code>1 <= k <= 10<sup>4</sup></code>
* <code>k <= nums1.length * nums2.length</code>
