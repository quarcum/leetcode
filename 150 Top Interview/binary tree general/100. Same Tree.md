# [100. Same Tree](https://leetcode.com/problems/same-tree/)  

### Easy level 

Given the roots of two binary trees <code>p</code> and <code>q</code>, write a function to check if they are the same or not.

Two binary trees are considered the same if they are structurally identical, and the nodes have the same value.  

<br />

**Example 1:**
![100 problem example 1 image](../../images/binary_tree_general/100_problem_example_1.png)
<pre>
<strong>Input:</strong> p = [1,2,3], q = [1,2,3]
<strong>Output:</strong> true
</pre>

**Example 2:**
![100 problem example 2 image](../../images/binary_tree_general/100_problem_example_2.png)
<pre>
<strong>Input:</strong> p = [1,2], q = [1,null,2]
<strong>Output:</strong> false
</pre>

**Example 3:**
![100 problem example 3 image](../../images/binary_tree_general/100_problem_example_3.png)
<pre>
<strong>Input:</strong> p = [1,2,1], q = [1,1,2]
<strong>Output:</strong> false
</pre>

<br />

**Constraints:**

* The number of nodes in both trees is in the range <code>[0, 100]</code>.
* <code>-10<sup>4</sup> <= Node.val <= 10<sup>4</sup></code>
