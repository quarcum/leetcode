# [290. Word Pattern](https://leetcode.com/problems/word-pattern/)  

### Easy level  

Given a <code>pattern</code> and a string <code>s</code>, find if <code>s</code> follows the same pattern.

Here **follow** means a full match, such that there is a bijection between a letter in <code>pattern</code> and a **non-empty** word in <code>s</code>. Specifically:

* Each letter in <code>pattern</code> maps to **exactly** one unique word in <code>s</code>.
* Each unique word in <code>s</code> maps to **exactly** one letter in <code>pattern</code>.
* No two letters map to the same word, and no two words map to the same letter.  

<br />

**Example 1:**
<pre>
<strong>Input:</strong> pattern = "abba", s = "dog cat cat dog"
<strong>Output:</strong> true
</pre>
**Explanation:**

The bijection can be established as:

* <code>'a'</code> maps to <code>"dog"</code>.
* <code>'b'</code> maps to <code>"cat"</code>.  

**Example 2:**
<pre>
<strong>Input:</strong> pattern = "abba", s = "dog cat cat fish"
<strong>Output:</strong> false
</pre>
**Example 3:**
<pre>
<strong>Input:</strong> pattern = "aaaa", s = "dog cat cat dog"
<strong>Output:</strong> false
</pre>

<br />  

**Constraints:**

* <code>1 <= pattern.length <= 300</code>
* <code>pattern</code> contains only lower-case English letters.
* <code>1 <= s.length <= 3000</code>
* <code>s</code> contains only lowercase English letters and spaces <code>' '</code>.
* <code>s</code> **does not contain** any leading or trailing spaces.
* All the words in <code>s</code> are separated by a **single space**.
