# [191. Number of 1 Bits](https://leetcode.com/problems/number-of-1-bits/)  

### Easy level   

Given a positive integer <code>n</code>, write a function that returns the number of **set bits**<sup>1</sup> in its binary representation (also known as the [Hamming weight](https://en.wikipedia.org/wiki/Hamming_weight)).  

**1.** A set bit refers to a bit in the binary representation of a number that has a value of <code>1</code>.  

<br />

**Example 1:**
<pre>
<strong>Input:</strong> n = 11
<strong>Output:</strong> 3
</pre>

**Explanation:**  
The input binary string **1011** has a total of three set bits.

**Example 2:**
<pre>
<strong>Input:</strong> n = 128
<strong>Output:</strong> 1
</pre>

**Explanation:**  
The input binary string **10000000** has a total of one set bit.

**Example 3:**
<pre>
<strong>Input:</strong> n = 2147483645
<strong>Output:</strong> 30
</pre>

**Explanation:**  
The input binary string **1111111111111111111111111111101** has a total of thirty set bits.  

<br />

**Constraints:**

* <code>1 <= n <= 2<sup>31</sup> - 1</code>  

**Follow up:** If this function is called many times, how would you optimize it?
