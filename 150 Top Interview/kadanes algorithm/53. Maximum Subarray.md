# [53. Maximum Subarray](https://leetcode.com/problems/maximum-subarray/)  

### Medium level 

Given an integer array <code>nums</code>, find the **subarray**<sup>1</sup> with the largest sum, and return *its sum*.  
**1.** A **subarray** is a contiguous **non-empty** sequence of elements within an array.

<br />

**Example 1:**
<pre>
<strong>Input:</strong> nums = [-2,1,-3,4,-1,2,1,-5,4]
<strong>Output:</strong> 6
<strong>Explanation:</strong> The subarray [4,-1,2,1] has the largest sum 6.
</pre>

**Example 2:**
<pre>
<strong>Input:</strong> nums = [1]
<strong>Output:</strong> 1
<strong>Explanation:</strong> The subarray [1] has the largest sum 1.
</pre>

**Example 3:**
<pre>
<strong>Input:</strong> nums = [5,4,-1,7,8]
<strong>Output:</strong> 23
<strong>Explanation:</strong> The subarray [5,4,-1,7,8] has the largest sum 23.
</pre>  

<br />

**Constraints:**

* <code>1 <= nums.length <= 10<sup>5</sup></code>
* <code>-10<sup>4</sup> <= nums[i] <= 10<sup>4</sup></code>  

<br />

**Follow up:** If you have figured out the <code>O(n)</code> solution, try coding another solution using the **divide and conquer** approach, which is more subtle.
