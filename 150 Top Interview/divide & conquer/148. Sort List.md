# [148. Sort List](https://leetcode.com/problems/sort-list/)  

### Medium level  

Given the <code>head</code> of a linked list, return *the list after sorting it in **ascending order***.  

<br />

**Example 1:**
![148 problem example 1 image](../../images/divide_&_conquer/148_problem_example_1.png)  
<pre>
<strong>Input:</strong> head = [4,2,1,3]
<strong>Output:</strong> [1,2,3,4]
</pre>

**Example 2:**
![148 problem example 2 image](../../images/divide_&_conquer/148_problem_example_2.png)  
<pre>
<strong>Input:</strong> head = [-1,5,3,4,0]
<strong>Output:</strong> [-1,0,3,4,5]  
</pre>

**Example 3:**
<pre>
<strong>Input:</strong> head = []
<strong>Output:</strong> []
</pre>

<br />

**Constraints:**

* The number of nodes in the list is in the range <code>[0, 5 * 10<sup>4</sup>]</code>.
* <code>-10<sup>5</sup> <= Node.val <= 10<sup>5</sup></code>

<br />

**Follow up:** Can you sort the linked list in <code>O(n logn)</code> time and <code>O(1)</code> memory (i.e. constant space)?
